# Chrono Down

## Available format codes

Code | Outputs
------------ | -------------
`$h` | hours
`$m` | minutes 
`$s` | seconds

## Format examples

Example format | Live output
------------ | -------------
`$h`:`$m` | 10:15 
`$h`:`$m`:`$s` | 10:15:35
Going live in: `$h`:`$m`:`$s` | Going live in: 10:15:35
`$h` foo `$m` minutes `$s` seconds`| 10 foo 15 minutes 35 seconds
