# How to perform a fresh installation

In case you have a problem with the application on your specific system only, then these steps are a good idea. The next few steps are required to have a complete fresh installation when you previous installed Snaz and would like to have a complete fresh start.

<Steps>


## Uninstall installed version

* Close Snaz if it is running !
* Uninstall the currently installed Snaz from your system. You can do this by uninstalling Snaz from the `Programs and Features` window from windows or execute the `unins000.exe` executable file inside the current Snaz installed directory.

## Remove all config files

* Config files are located in the folder `JimsApps` inside `C:\Users\YOUR_USERNAME\AppData\Local`. Remove the folder `JimsApps` to erase all config files.

## Installing the latest release

* Latest Snaz version can be downloaded [here](https://github.com/JimmyAppelt/snaz/releases)

</Steps>

Great, you have a clean installation now 🌟
