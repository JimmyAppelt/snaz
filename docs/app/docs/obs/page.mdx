# OBS Integration

Any stream software will work if it is able to read files feel free to commit information about other players!

## OBS Studio

### Add a text source in Studio

* Press the <Highlight>+</Highlight> sign in OBS Studio and select <Highlight>Text (GDI+)</Highlight>

![Source](https://i.gyazo.com/b63a8578a2f14805a970e8db618f159a.png)

### Link a Snaz text file in Studio

* In the property's of the source check mark <Highlight>Read from file</Highlight>
* Press the <Highlight>browse</Highlight> button and select the file you would like to link

>[!TIP]
>
> For good quality text, make the font size very big in the source and scale it down afterwards in the scene)

![Link](https://i.gyazo.com/5ea5db927e7b26cd40e6728496e3b4ac.png)

## OBS Classic

### Add a text source in Classic

* **Right click** in the sources box and select **Add → Text**

![Source](https://i.imgur.com/oNiXWkA.png)

### Link a Snaz text file in Classic

* In the property's of the source check mark <Highlight>Use Text From File</Highlight>
* **Paste** the text file link or press the <Highlight>browse</Highlight> button and select the file you would like to link

>[!TIP]
>
> For good quality text, make the font size very big in the source and scale it down afterwards in the scene)

![Link](https://i.imgur.com/8X7B4C4.png)
