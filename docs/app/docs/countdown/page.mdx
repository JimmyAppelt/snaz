# Countdown

## Available format codes

Code | Outputs
------------ | -------------
`$d` | days
`$h` | hours
`$m` | minutes 
`$s` | seconds

## Format examples

Example format | Live output
------------ | -------------
`$h`:`$m` | 1:15
`$h`:`$m`:`$s` | 1:15:35 
`$h` foo `$m` | 1 foo 15
`$h`h `$m`m `$s`s | 1h 15m 35s 
`$h` hour `$m` minutes `$s` seconds | 1 hour 15 minutes 35 seconds
Extension pack release in `$h` hour `$m` minutes  `$s` seconds | Extension pack release in 1 hour 15 minutes 35 seconds
