# FAQ

## What do I do if my text files are not updating?

* Check if Snaz has necessary permissions to edit all text files
 * Try running Snaz as `Run as administrator`
 * Don't install Snaz in a `Program Files` directory  

## Is or will Snaz be multi language?

* We currently have no plans to make Snaz multi language

## v1.12.7.0 vs v1.12.6.0

**Twitch** and **Playing Now** modules are **not** in the v1.12.7.0 release, besides that both are the same.

### Why?

Due to the end of Snaz v1 development. To give Snaz more survivability as a standalone program without any external program to be able to break Snaz without maintenance.

If you would like to keep Twitch and Playing Now, download 1.12.6.0 on the release page or don't update to 1.12.7.0 as long as both features keep working.
