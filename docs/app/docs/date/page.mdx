# Date

## Available format codes

Date format | Outputs
------------ | -------------
`$dd-MM-yy` | 25-06-13
`$dd-MM-yyyy` | 25-06-2013
`$dd MMMM yyyy` | 25 june 2013
`$dddd dd MMMM yyyy` | Tuesday 25 june 2013

Code | Outputs
------------ | -------------
`$date` | date

## Format examples

Example format | Live output
------------ | -------------
`$date` | Tuesday 25 june 2013 *(depending on date format)*
Today: `$date` | Today: Tuesday 25 june 2013 *(depending on date format)*
