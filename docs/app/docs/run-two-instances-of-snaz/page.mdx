# Run two instances of Snaz

<Steps>

## Duplicate your installation

This can be done in two ways:

 * Copy the current installation into a new folder e.g. `~/Snaz2`
 * Open the `Setup.exe` file once again and install into another folder e.g. `~/Snaz2`
