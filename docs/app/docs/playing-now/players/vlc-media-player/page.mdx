# VLC Media Player

<p className="with-image-icon mt-[1.25em]">![VLC Media Player](https://i.imgur.com/ghuNBOU.png) [VLC Media Player](https://www.videolan.org/vlc/)</p>

## Available format codes

Code | Outputs
------------ | -------------
`$artist` | artist name
`$song` | song name
`$album` | album name
`$artist_upper` | ARTIST NAME
`$song_upper` | SONG NAME
`$album_upper` | ALBUM NAME

## Format examples

Example format | Live output
------------ | -------------
`$artist` - '`$song`' | Faith No More - 'Easy'
Artist: `$artist` Song: `$song` | Artist: Faith No More Song: Easy
`$artist` - '`$song`' - `$album` | Faith No More - 'Easy' - Angel Dust
`$artist` - foo - '`$song`' | Faith No More - foo - 'Easy'
`$artist_upper` - foo - '`$song`' | FAITH NO MORE - foo - 'Easy'

## Specific notes

* Album and album art are queried from online API and requires [authentication](/docs/playing-now/spotify-credentials).
* You will only receive correct data from music files not video's (at least at this time)
