## Available format codes

Code | Outputs
------------ | -------------
`$artist` | artist name
`$song` | song name
`$album` | album name
`$artist_upper` | ARTIST NAME
`$song_upper` | SONG NAME
`$album_upper` | ALBUM NAME

## Format examples

Example format | Live output
------------ | -------------
`$artist` - '`$song`' | Faith No More - 'Easy'
Artist: `$artist` Song: `$song` | Artist: Faith No More Song: Easy
`$artist` - '`$song`' - `$album` | Faith No More - 'Easy' - Angel Dust
`$artist` - foo - '`$song`' | Faith No More - foo - 'Easy'
`$artist_upper` - foo - '`$song`' | FAITH NO MORE - foo - 'Easy'

## Which is the default window title notation of Foobar2000 ?

The default notation:

```console
[%album artist% - ]['['%album%[ CD%discnumber%][ #%tracknumber%]']' ]%title%[ '//' %track artist%]
```

## Which is the Custom Capture window title for Foobar2000 ?

The Custom Capture notation:

```console
%title% '♫' %artist% '♫' %track artist% '♫' %albumartist%
```

## Why would i need to use Custom Capture ?

In case you have a large amount of songs that where snaz is unable to find the correct artist name and/or song name, u have this option to turn on (make sure you use the Custom Capture window title if you turn this feature on). I still advice to contact me if you have such an issue. Most probably you are using a custom window text title and not the default one. The window title notation however is very important to capture the correct data.

If you don't care ... you can always leave it in the custom capture notation and enjoy !
