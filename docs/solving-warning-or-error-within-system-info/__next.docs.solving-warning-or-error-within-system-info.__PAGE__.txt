5:T4db,# Solving warning or error within System Info

## Cannot Load Counter Name data

```console
Cannot Load Counter Name data because an invalid index was read from the registry
```

This issue comes up in cases when one or more performance counters on your system are corrupted.

### Rebuild all performance counters:

* Open command prompt (with Admin privileges)
* Run command: `lodctr /R`

The message with: `Info: Successfully rebuilt performance counter setting ...` will appear on success.

In case you receive the message `Unable to rebuild performance counter setting from system backup store, error code is 2` possible solutions:

* Close all running programs
* Make sure you use `lodctr /R` with uppercase `R`
* If in directory `system32` move to directory `SysWOW64` *(with cd.. > cd syswow64)* and retry the `lodctr /R` command in this directory

After successfully rebuilt, re-open Snaz and check if same warning occurs. If the same warning occurs, please feel free to open a new issue.
